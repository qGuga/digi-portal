Find out which server Dungeons you are already ready to run! Select your party role and enter your current stats (with buffs and gear active).

💡 You can enter abbreviated values (e.g., 80k, 14.5k, 1.8m) or the full number (e.g., 80000).

⚠️ For percentage stats, include the % symbol (e.g., 350% for 350% CT).

ℹ️ Note on Requirements: The minimum stat values used in this tool follow the official recommendations provided by the server Staff. They serve as a safe baseline to avoid missed hits (Miss) and ensure raid survivability.
